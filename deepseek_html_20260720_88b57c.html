🚀 Create a React Project & Host on GitHub Pages

Interactive step‑by‑step guide for absolute beginners

0 of 10 steps completed

1 Check Node.js installation

React needs Node.js. Open a terminal (in VS Code: Terminal → New Terminal) and check versions:

node -v

Expected output: v18.17.0 or higher.

npm -v

Expected output: 9.6.7 or higher.

If not installed: Download LTS version from nodejs.org (left button). Restart terminal after installation.
2 Create a React project with Vite

Navigate to your desired folder (e.g., Desktop) and run the Vite creator:

cd Desktop
npm create vite@latest my-react-page -- --template react

When prompted to install create-vite@latest, type y and Enter.

cd my-react-page
npm install

Open the folder in VS Code:

code .
3 Explore project structure

In VS Code’s file explorer you’ll see:

  • index.html – the main HTML page.
  • src/ – all React code.
    • main.jsx – entry point
    • App.jsx – main component we’ll edit
    • App.css – styles for App
  • package.json – project configuration

We’ll only touch App.jsx and package.json.

4 Run the app locally 
npm run dev

Look for http://localhost:5173/ in the terminal, hold Ctrl (or Cmd) and click it. The browser will show a Vite + React starter page.

Keep the server running. To stop later, press Ctrl+C.

6 Prepare for GitHub Pages

a) Install gh-pages package:

npm install gh-pages --save-dev

b) Set homepage URL in package.json:
Add this line right after "version" (replace username and repo name):

"homepage": "https://yourusername.github.io/my-react-page",

c) Add deploy scripts: In "scripts" section of package.json, add:

"predeploy": "npm run build",
"deploy": "gh-pages -d dist"

Ensure the last script doesn’t have a trailing comma. Example final scripts:

"scripts": {
  "dev": "vite",
  "build": "vite build",
  "preview": "vite preview",
  "predeploy": "npm run build",
  "deploy": "gh-pages -d dist"
}
7 Fix asset paths for GitHub Pages

Open vite.config.js and add a base property (use your repo name):

import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  base: '/my-react-page/',   // <-- your repo name here
})
Important: The base value must match your GitHub repository name exactly (case‑sensitive), with slashes.
8 Create a GitHub repo and push code

Using GitHub Desktop:

  1. In GitHub Desktop, File → Add local repository, choose your my-react-page folder.
  2. If warned “not a Git repository”, click create a repository.
  3. Click Publish repository (top right).
  4. Name it my-react-page (exactly as in previous steps), keep it Public.
  5. Click Publish Repository.

Now your code is on GitHub at https://github.com/<your-username>/my-react-page.

9 Deploy to GitHub Pages

In your terminal (inside the project folder), run:

npm run deploy

This builds the app and pushes the dist folder to a gh-pages branch.

After it finishes, go to your GitHub repository → Settings → Pages. Under “Branch”, select gh-pages and / (root), then click Save.

After a minute or two you’ll see: “Your site is live at https://...github.io/my-react-page/”

Visit that URL – your React app is live! 🎉

10 Update your site in the future
  • Make code changes and save files.
  • Test locally with npm run dev.
  • Commit and push using GitHub Desktop (summary → “Commit to main” → “Push origin”).
  • Run npm run deploy again.

Your live site will update in a minute or two.

⚠️ Troubleshooting common issues
  • Blank page after deployment? – Double‑check base in vite.config.js and homepage in package.json.
  • “fatal: not a git repository” – Use GitHub Desktop to create/publish the repository.
  • gh‑pages command not found – Run npm install gh-pages --save-dev again.
